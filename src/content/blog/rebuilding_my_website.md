I decided it was time I updated my website and made it a little more interesting. Initially I created my website using Jekyll just because it's the default framework for GitHub Pages. But it's a little bit dated now and I wanted to switch to something newer that would allow me do more with it.

After doing some research and testing out a few different frameworks, I decided to go with [Astro](https://astro.build/). It seems to be the new standard for simple static websites and it also provides a lot of flexibility. For the design, I went with Manuel Ernesto's [Astrofy](https://github.com/manuelernestog/astrofy) template. I'm a big fan of the minimalist layout it gives you.

Anyway I'll keep this short and stop there. If you're interested in getting started with Astro, check out the [Tutorial](https://docs.astro.build/en/tutorial/0-introduction/).
